# homebrew-tap

Homebrew formulae von [@sipfl](https://github.com/sipfl).

## Installation

```sh
brew install sipfl/tap/worktt
```

oder explizit:

```sh
brew tap sipfl/tap
brew install worktt
```

## Formulae

- **worktt** — Arbeitszeiten aus der macOS `knowledgeC.db` ableiten ([Repo](https://github.com/sipfl/worktt))
