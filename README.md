# homebrew-tap

Homebrew formulae by [@sipfl](https://github.com/sipfl).

## Installation

```sh
brew install sipfl/tap/worktt
```

or explicitly:

```sh
brew tap sipfl/tap
brew install worktt
```

## Formulae

- **worktt** — derive working hours from the macOS `knowledgeC.db` ([repo](https://github.com/sipfl/worktt))
